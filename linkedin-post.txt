Google made the Workspace CLI generally available today.
What does it take to go from one curl command to an agent reading Gmail, Drive and Calendar?

One curl command installs a single static binary. Before you sign in, it lists its own actions, the OAuth scopes each one needs and the JSON it returns.

Sign-in is per command. The read-only bundle leaves out drive.file, which Drive's list and search commands require.

On launch day the OAuth client's project decided access: a new personal-mode project was refused, and a project in the Workspace Developer Preview returned data.

New tools arrive from the MCP servers on every run, with no upgrade.
