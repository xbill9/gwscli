# gwscli

Install and use the Google Workspace CLI (`gwscli`) on Linux: a step by step article.

- `devto-gwscli.md` — the article (dev.to source)
- `evidence/` — captured output of every command shown in the article (gwscli 1.0.6.1026726559, 2026-11-24)
- `make_cover.py` — draws the textless covers, named by a hash of their bytes
